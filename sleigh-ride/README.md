# Christmas Sleigh Ride (first-person): Aaron Atkinson Realty

A first-person, 3D lane-runner: you're in the driver's seat behind two reindeer, racing down a snowy street lined with houses, Aaron Atkinson Realty yard signs ("SOLD!" / "FOR SALE") and a "Merry Christmas from Aaron Atkinson Realty" banner.

- **Steer:** swipe or tap left/right (phone), ← → / A D (computer)
- **Fly over snowbanks:** swipe up or tap the middle (phone), ↑ / W / Space (computer)
- Collect keys, dodge snowmen. 3 lives, 60 seconds; the sleigh speeds up as you go.

It's one `index.html` plus `logo.png`. It loads the three.js 3D library (v0.160.0) from the jsDelivr CDN, so players need an internet connection.
The settings block at the top of the module script works like the 2D version: `leadEndpoint`, `playEndpoint`, `phone`, `website`, `charity`, round length and speed.
